Política de privacidad de Jarvis

Última actualización: 8 de octubre de 2026.

Quién la usa

Jarvis es una aplicación de uso estrictamente personal. Su único usuario es su propio dueño, que la creó y la administra.

Qué datos de Google usa

  • Gmail (solo lectura): para resumir correos importantes cuando el dueño lo pide. Jarvis no envía, borra ni modifica correos.
  • Google Calendar: para consultar la agenda y crear los eventos y recordatorios que el dueño pide.

Cómo se tratan

Los datos se procesan en el computador del dueño y se usan solo para responderle a él. No se venden, no se comparten con terceros, no se usan para publicidad ni para entrenar modelos de inteligencia artificial generales. El uso de la información recibida de las API de Google cumple con la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Cómo revocar el acceso

El dueño puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions.
